# Hello World - Python

## Overview

This is a simple Hello World program written in Python as part of the CSE 310: Applied Programming course at BYU-Pathway Worldwide.

The program prints "Hello World!" to the console along with a brief personal introduction from the developer.

## Development Environment

- **Language:** Python 3
- **IDE:** Visual Studio Code
- **Operating System:** Windows / Mac / Linux

## How to Run the Program

1. Make sure Python 3 is installed on your computer.
2. Clone this repository:
   ```
   git clone https://github.com/EbenezerOppong4127/HelloWorldPython.git
   ```
3. Navigate into the project folder:
   ```
   cd HelloWorldPython
   ```
4. Run the program:
   ```
   python hello_world.py
   ```
